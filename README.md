 Online Gaming Tournament Management System

 Project Overview
The Online Gaming Tournament Management System is a DBMS mini project developed using MySQL. It stores and manages information about players, games, teams, tournaments, registrations, and winners.

 Objectives
- To maintain player information.
- To store details of different games.
- To manage gaming teams.
- To maintain tournament schedules and prize money.
- To record tournament registrations.
- To store winners and prize details.

 Technologies Used
- Database: MySQL
- Language: SQL
- Tool: MySQL Workbench

 Database Tables
This project contains six tables:

1. **Players** — Stores player details.
2. **Games** — Stores game information.
3. **Teams** — Stores team details.
4. **Tournaments** — Stores tournament schedules and prize money.
5. **Registrations** — Stores player registration records.
6. **Winners** — Stores tournament results and prizes.

SQL Concepts Used
- CREATE DATABASE
- CREATE TABLE
- INSERT INTO
- SELECT
- WHERE
- ORDER BY
- PRIMARY KEY

 How to Run the Project
1. Install MySQL or open MySQL Workbench.
2. Download the `GamingTournament.sql` file from this repository.
3. Open the SQL file in MySQL Workbench.
4. Execute the SQL script.
5. Run the SELECT queries to view the results.

 Project Type
DBMS Mini Project

## 📝 Conclusion
This project demonstrates the basic concepts of database management using MySQL. It provides a simple way to organize and retrieve gaming tournament information using SQL queries.
